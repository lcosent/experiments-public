# Sources

All variant data are public.

| Source | Used for |
|---|---|
| [ClinVar](https://www.ncbi.nlm.nih.gov/clinvar/) | Variant identifiers, prior submission counts, classification |
| [gnomAD v4](https://gnomad.broadinstitute.org/) | Population allele frequency, gene constraint |
| [UniProt](https://www.uniprot.org/) | Domain and functional annotation |
| [OMIM](https://www.omim.org/) | Disease association |

The bundled `variants.jsonl` is a hand-curated subset of well-known disease genes. The classifications shown reflect majority ClinVar submitter consensus as of late 2025; some variants have evolving classifications and may not match current consensus.
